# 💝 Our Story Workspace

Welcome to the **Our Story** project workspace. This repository contains the relationship milestone app and memory scrapbooking experiences.

## 📂 Repository Layout

- [`my-loved/`](file:///D:/workspace/Our-Story/my-loved) — The primary Next.js 16 Web Application for tracking milestone counters, quiz logs, memory journals, and interactive letter surprises.
  - See the detailed [`my-loved/README.md`](file:///D:/workspace/Our-Story/my-loved/README.md) for core features, motion design properties, and installation guides.

## 🚀 Quick Start

To start the Next.js relationship application, navigate to the `my-loved` directory and start the dev server:

```bash
cd my-loved
pnpm install
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
